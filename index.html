บริจาค API Key (KKU IntelSphere) 🔑
วิธีขอ API Key ฟรีจาก KKU IntelSphere
  1. เข้า gen.ai.kku.ac.th แล้ว login ด้วยบัญชี KKU
  2. คลิกไอคอน ⚙️ Settings ที่แถบด้านซ้าย
  3. เลือกเมนู API Platform (For developers)
  4. ในแท็บ Introduction กด Copy ที่ช่อง api_key (หรือกด Generate New Key ถ้ายังไม่มี) แล้วนำมาวางด้านล่าง
Key ของคุณจะถูกใช้ทำอะไรบ้าง
  • ตอบคำถามของเพื่อนๆ ผ่าน MDKKUQUIZ AI Passport EIEI บนเว็บนี้
  • ทีมพัฒนาใช้โควต้าจาก pool เพื่อปรับปรุงเว็บ (เช่น สร้างคำอธิบายเฉลย)
  • Key ที่บริจาคอาจถูกใช้รันงานสร้างเนื้อหาแบบ batch ช่วงกลางคืน โดยจำกัดการใช้ต่อ Key ต่อคืน

Key จะถูกตรวจสอบกับระบบ IntelSphere ก่อนบันทึก
